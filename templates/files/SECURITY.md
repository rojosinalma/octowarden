# Security policy

## Supported versions

Only the latest release of ${{ values.repo }} receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Report it privately through
[GitHub's private vulnerability reporting](https://github.com/${{ values.full_name }}/security/advisories/new).

Include what you found, how to reproduce it and the impact you expect.
You get an answer within a few days. Once a fix is out, the advisory is published
and you are credited unless you ask not to be.
